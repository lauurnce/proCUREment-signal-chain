# P2.2 plan: tokens and components in the Lab

## Context
You chose Direction A (D-025) and settled 6 open decisions (D-026 to D-031). Now we turn the `adi-theme` skill into real code tokens and show the key UI pieces in `/lab`, so we judge them on screen. The app still has only a few tokens (and the old Approve green).

## Steps

**1. Tokens (two council members in parallel, then I merge)**
- **brand-guardian** writes the UI tokens straight into `apps/web/src/theme/tokens.ts` and `theme.css`:
  - colors by role, status colors (Approve green #1A7F50), and track accents (UI and world values, badge shapes)
  - type scale, spacing, radii and elevation
  - the motion tokens from the skill, plus the new D-030 values
  - It also writes `docs/design/SCREEN_EXCEPTIONS.md`: every screen-only addition (D-011), each with its hex, why it is needed, and its contrast.
- **world-artist** writes the 3D palette as a spec in `docs/design/WORLD_PALETTE.md`. It includes the navy slab edge (D-029), the capiz lamp, the Endorsement Bridge and the folder tabs. I copy these values into the `world` object in `tokens.ts`.
- Nothing else is hard coded. Anything that reads a color reads it from the tokens.
- I extend `tokens.test.ts` so it checks every value in the CSS and every contrast ratio the Lab shows. A contrast that fails the check fails the test.

**2. Lab sections** (`apps/web/src/lab/`, one small file per section, driven by the tokens)
1. Color swatches, grouped by role. Each one shows its name, hex and contrast on white, panel or navy, with an AA pass or fail mark. Screen-only exceptions are marked "Needs approval (D-011)".
2. Typography specimen: every style from the scale, with its size, line height and weight.
3. Status chips: working, waiting, meeting, break and off. Each has a shape, a color and a text label, never color alone.
4. Name tag pill: "CM 03 helper" with the track badges (star, outline triangle, diamond, square) and a status dot, in day and night versions.
5. Stats HUD card: big numbers over mono labels, for example "Handoffs today" and "Needs you".
6. Panel card: a fictional PO amendment from Luzon Precision Components Corp. It shows "PO amendments · Step 3 of 4", "Why this came to you", and the four buttons Approve, Hold, Send back and Instruct. Buttons shrink to 0.97 when pressed, and the key hints A, H, S, I are shown.
- Plain page, no 3D. Copy uses sentence case, no em dashes, and fictional data only. The About note stays.
- I add a helper to compute contrast ratios, with a unit test.

**3. Screenshots and check**
- `shots.spec.ts` takes a full-page shot of `/lab`, because the page is now long.
- I run `pnpm check` and `pnpm shots`, then look at the lab screenshots myself and fix what looks wrong.
- The brand-guardian reviews the screenshots against the skill. I fix what it finds.
- Then I show you the screenshots and the D-011 exception list to approve.
